# KHING Portfolio Website

A clean, minimalist portfolio website showcasing artistic works and installations. Built with a focus on typography, spacing, and elegant presentation of visual content.

## Features

- **Minimalist Design**: Clean, gallery-style layout with emphasis on content
- **Responsive Layout**: Works seamlessly across desktop, tablet, and mobile devices
- **Interactive Navigation**: Sidebar navigation with year-based organization and active section highlighting
- **Smooth Scrolling**: Enhanced user experience with smooth scroll behavior
- **Back to Top**: Convenient navigation back to the top of the page
- **Typography-Focused**: Careful attention to typography hierarchy and spacing



## Design Philosophy

The website follows a minimalist gallery aesthetic with:
- Clean typography using Times New Roman
- Generous white space and careful spacing
- Subtle color palette (black, white, gray)
- Focus on content presentation over decorative elements
- Responsive design that adapts to different screen sizes

## Layout Components

### Top Navigation Bar
- Fixed position with logo and main navigation
- Sticky behavior for easy access
- Responsive design that stacks on mobile

### Sidebar Navigation
- Year-based organization of projects
- Active section highlighting
- Smooth scrolling to sections
- Converts to horizontal layout on mobile

### Main Content Area
- Project showcase with detailed descriptions
- Image galleries for each work
- Consistent typography and spacing
- Maximum width for optimal readability

## Interactive Features

- **Scroll-based Navigation**: Sidebar highlights current section based on scroll position
- **Back to Top Button**: Appears after scrolling down, provides quick navigation
- **Smooth Scrolling**: Enhanced user experience when navigating between sections
- **Responsive Behavior**: Layout adapts to different screen sizes

## Typography

- **Primary Font**: Times New Roman (serif)
- **Font Sizes**: Carefully scaled hierarchy (14px base, 2.5rem for main title)
- **Letter Spacing**: Subtle adjustments for readability
- **Line Height**: Optimized for comfortable reading

## Color Palette

- **Primary Text**: #000 (black)
- **Secondary Text**: #666 (medium gray)
- **Background**: #f8f8f8 (light gray)
- **Accents**: Minimal use of color for focus

## Responsive Breakpoints

- **Desktop**: Full layout with sidebar
- **Tablet (1024px)**: Adjusted spacing and sidebar width
- **Mobile (768px)**: Stacked layout, sidebar becomes horizontal
- **Small Mobile (480px)**: Further optimized spacing

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Getting Started

1. Open `index.html` in a web browser
2. Navigate through projects using the sidebar
3. Scroll to explore content
4. Use the back to top button for quick navigation

## Customization

### Content
- Update project information in the HTML
- Replace placeholder images with actual artwork
- Modify project descriptions and metadata

### Styling
- Adjust typography in `css/style.css`
- Modify spacing and layout
- Update color scheme if needed
- Customize responsive breakpoints

### Functionality
- Enhance JavaScript interactions in `js/main.js`
- Add new interactive features
- Modify scroll behavior
